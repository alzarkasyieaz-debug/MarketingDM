## 4. Senarai teknik compositing yang digunakan

| Teknik | Pelaksanaan |
|---|---|
| **AI Cut-Out / rotoscoping** | rembg `u2net_human_seg` pada setiap bingkai (2010 bingkai), smoothing temporal 3 bingkai, erode 1 px + feather, **decontamination tepi** (buang limpahan cahaya langit → tiada halo putih pada bahu/kopiah) |
| **3D typography di belakang penyampai** | Huruf extrude 22 lapisan (gangsa → emas), muka emas metalik bergradien + bevel + garis gelap, glow & bayang dijatuhkan ke latar; masuk dengan putaran-Y perspektif + skala, kemudian *push-in*; **gold light sweep** merentasi muka huruf |
| **Foreground occlusion** | Susunan lapisan: latar → bayang teks → teks 3D → penyampai (matte) → grafik → subtitle. Teks tidak pernah menutup muka |
| **Environment matching** | Pendedahan & warna penyampai disesuaikan (malam: -20 % + suam; studio: rim emas), **rim light** & **light wrap** dari latar |
| **Depth parallax / push-in** | Latar, teks 3D dan penyampai di-zoom pada kadar berbeza |
| **Cut-out transition** | Penyampai kekal, latar baru terbuka secara bulatan di belakangnya (0:07.3) |
| **Background replacement** | Kaabah malam, Masjidil Haram siang, studio maya emerald-emas (corak bintang 8 bucu, gerbang Islamik emas, lantai berkilat, spotlight, light streak & zarah emas beranimasi) |
| **Depth-of-field** | Latar dikaburkan; babak Haram guna kabur bergradien (orang ramai dikaburkan kuat supaya individu tidak dapat dikenal pasti) |

Semua latar yang ditukar ialah **komposit kreatif**. Penyampai tidak didakwa berada di lokasi tersebut (tiada teks yang menyatakan begitu).

## 5. Audio & subtitle
- Suara asal: high-pass, low-pass, `afftdn` (noise reduction), compressor, loudnorm.
- Muzik: instrumental gaya Islamik **dijana sendiri** (oud maqam Hijaz + dengung + daf, `render/islamic_music.py`) – bebas hak cipta.
  Bahagian: sparse (hook–peluang) → full dengan daf (hadiah–syarikat) → calm (emosi) → end. Muzik ±15 dB di bawah suara + ducking automatik 7 dB.
- SFX dijana sendiri: impact (hook, setiap tulisan 3D, stamp), whoosh (peralihan, kad), riser (sebelum hadiah & CTA), sparkle (produk).
- Subtitle Bahasa Malaysia word-by-word dari suara sebenar; perkataan kunci huruf besar, perkataan aktif emas.
  Pembetulan transkrip: "tonton" → "tuan-tuan", "Darul Barat" → "Darul Mubarak", "perempuan" → "puan-puan", "Telekong" → "telekung".
- Zon selamat: subtitle pada y≈1430, chip/maklumat pada y≈1250, tajuk di atas kepala – tiada pertindihan; tiada teks di 380 px bawah.

## 8. Cara render semula
```bash
export SRC_DIR=/path/to/src WORK=/path/to/work   # src: master.mov, logo.png, poster_new.jpg (Zamzam), gifts/{bag.png,ihram.jpg,telekung.jpg}, broll/IMG_*.MOV
python3 render/segment.py          # AI cut-out matte setiap bingkai (≈15 min CPU)
bash render/prep_broll.sh          # HDR→SDR tonemap, potret 1080×1920, slow-mo
python3 render/compose.py          # komposit + 3D + grafik + subtitle → video_silent.mp4
python3 render/build_audio.py      # suara + muzik + SFX → mix.wav → MP4 akhir
PREVIEW="3.0,10.9,17.2" python3 render/compose.py   # pratonton bingkai pegun
```
Keperluan: ffmpeg (zscale), Python 3 + numpy, Pillow, opencv-python-headless, rembg, onnxruntime; transkrip: faster-whisper large-v3. Fon Inter & Caladea.
